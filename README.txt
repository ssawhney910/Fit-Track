OVERLOAD LOG - host on GitHub Pages (free)

1. github.com > New repository. Name it e.g. overload-log. Public (free Pages needs public unless you have Pro). Create.
2. In the new repo: Add file > Upload files. Drag in EVERYTHING from this folder
   (index.html, manifest.webmanifest, sw.js, xlsx.mini.min.js and the icons folder). Commit.
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root). Save.
4. After ~1 minute the site is at https://<your-username>.github.io/overload-log/
5. On your phone open that URL:
   - iPhone: Safari > Share > Add to Home Screen > Add. (Must be Safari.)
   - Android: Chrome > menu > Install app / Add to Home screen.
6. Always open it from the home-screen icon after that.

Your data is stored on the phone only. Export to Excel weekly (Settings > Export Excel, or the banner on the Train tab).
To update the app later, upload the new files over the old ones in the repo.
